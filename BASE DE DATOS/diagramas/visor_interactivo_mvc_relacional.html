1️⃣ VISTA (View)

Interfaz reactiva en React 18, Vite y Tailwind CSS. Renderiza catálogos, carritos y paneles administrativos sin acoplamiento a base de datos.

  • • Catalogo.jsx: Filtros en tiempo real por tela y precio.
  • • CarritoDrawer.jsx: Liquidación de metraje continuo y cupones.
  • • ResumenAdmin.jsx: Gráficos Recharts de ventas y stock.
  • • App Android: Wrapper nativo Kotlin con WebView.
BACKEND Puerto 8081

2️⃣ CONTROLADOR (Controller)

Servidor HTTP nativo en Vanilla Java 17 con pool de 32 hilos concurrentes. Aplica validaciones, seguridad DevSecOps y orquestación.

  • • ManejadorBase: CORS, Rate Limit (120 req/min) y X-Correlation-ID.
  • • ManejadorProductos: Endpoints /api/productos (GET, POST, PUT, DELETE).
  • • ManejadorPedidos: Transaccionalidad de compras e inventario.
  • • ManejadorSalud: Probes /health/live y /health/ready.
PERSISTENCIA & DOMINIO Puerto 5432

3️⃣ MODELO (Model)

Entidades de dominio Java + DAOs JDBC con pool HikariCP + motor relacional PostgreSQL 17 con bloqueo a nivel de fila.

  • • Entidades: Producto, Pedido, Usuario, LoteInventario.
  • • DAOs: ProductoDAO, PedidoDAO, InventarioDAO (SQL parametrizado).
  • • PostgreSQL 17: 25 Tablas 3FN, Vistas SQL y Transacciones ACID.
  • • SELECT ... FOR UPDATE: Previene sobreventa simultánea de telas.

⚡ Ciclo de Vida Transaccional MVC: Compra de Tela y Descuento de Stock

Demostración del flujo coordinado entre la Vista, el Controlador, el Modelo y el motor PostgreSQL ante una orden de compra:

1

Vista (React)

Cliente pulsa "Confirmar Pedido". Se genera JSON con carrito y dirección.

2

Controlador (Java)

ManejadorBase valida CORS, Rate Limit y genera X-Correlation-ID.

3

Modelo (DAOs)

PedidoDAO inicia transacción: BEGIN TRANSACTION con HikariCP.

4

PostgreSQL 17

SELECT ... FOR UPDATE bloquea la fila de la tela y descuenta stock.

5

Respuesta 201

COMMIT, retorno de ID de orden y renderizado reactivo en la Vista.

Operación SQL Transaccional en Modelo (PostgreSQL) Nivel de Aislamiento: READ COMMITTED 
BEGIN TRANSACTION;
  -- Bloqueo pesimista para evitar carreras en ventas simultáneas
  SELECT id, stock FROM productos WHERE id = 1 FOR UPDATE;
  
  -- Inserción de la orden comercial y sus ítems
  INSERT INTO pedidos (usuario_id, monto_total, estado, estado_pago) VALUES (5, 85000.00, 'pending', 'paid');
  INSERT INTO items_pedido (pedido_id, producto_id, cantidad, precio_por_metro, subtotal) VALUES (12, 1, 3.4, 25000.00, 85000.00);
  
  -- Descuento exacto de metros del stock
  UPDATE productos SET stock = stock - 3.4 WHERE id = 1;
COMMIT TRANSACTION;
